# проект реализации приложения на базе Django REST framework, в котором каждый желающий может размещать свои полезные привычки
## В проекте реализовано приложение usefulthings:
* в модуле models приложения описана модель для привычки
* в модуле views приложения реализованы классы для создания/изменения/удаления/просмотра привычек,
определены права доступа
* в модуле urls приложения прописаны пути для контроллеров
* в модуле serializers описаны классы сериализаторов для привычки
* в модуле paginators описан класс пагинации
* в модуле services описана функция отправки уведомления в телеграмм
* в модуле tasks описана периодическая задача отправки уведомлений в телеграмм за 5 минут до начала выполнения привычки

## Установка:
1. Клонируйте репозиторий:
```git clone git@github.com:elenasyurtukova/DRFControlProject.git```

2. Установите библиотеки из pyproject.toml:
```poetry install```

3. На основе файла .env.sample в корне проекта создайте 2 файла:
   - env - для локального запуска, в нем переменные для docker hub нужно удалить
   - env.docker - для развертывания проекта на сервере

5. Установка Docker:
   Для работы с Docker если вы используете Windows/macOS установите на ваш 
   компьютер приложение Docker Desktop  https://www.docker.com/products/docker-desktop,
   а если - Linux можно установить Docker на примере Ubuntu.
   Официальная инструкция по установке находится по ссылке: 
   https://docs.docker.com/engine/install/ubuntu/.

## Запуск проекта:
1. Запуск проекта c помощью Docker Compose:
   1. запускаем redis через запуск сервера redis и redis-cli
   2. запускаем celery командой в терминале: python run_celery.py
   3. запуск всех сервисов: docker compose --env-file .env.docker up
   4. во 2-м терминале выводим список всех контейнеров и их текущее состояние:
   docker compose --env-file .env.docker ps
   
   После запуска веб-приложение будет доступно по адресу: http://localhost:8000

2. В проекте реализовано CI/CD с использованием GitHub Actions, для этого создан файл ci.yml в .github/workflows
   Т.е. каждый раз при push или pull request в репозиторий будет запускаться проверка кода на ошибки, запуск тестов 
   и развертывание приложения на сервере
   Шаги по запуску деплоя:
   1. Подключитесь к вашему серверу по SSH и настройте его
   2. Установите Docker и Docker Compose на сервере с официального сайта
   3. Настройте безопасность (файервол)
   4. Для работы со статическими файлами в проекте используется веб-сервер Nginx
   5. Установите Git на сервере
   6. Добавьте секреты всех переменных из файла .env.sample в настройках github
   Kаждый раз при push или pull request в репозиторий будет запускаться проверка кода на ошибки, запуск тестов 
   и автоматический деплой приложения на сервере.
   При успешном деплое приложение будет доступно по адресу публичного IP-адреса вашего сервера
